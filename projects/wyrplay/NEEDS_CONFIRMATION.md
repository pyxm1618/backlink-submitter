# Fields Still Not Verified

Normal directory submissions can proceed without additional user input for:
name, URL, public email, title, SEO keywords, short/medium/long descriptions, categories, tags,
pricing, platform, logo, screenshots, audiences, use cases, and features.

The following are intentionally blank because they are not verified:
- Founder name
- Founded / launch date
- Phone
- Street address
- Team size
- Funding
- Revenue
- Official social accounts
- Product demo/video URL
- App Store / Google Play links

Policy:
- Optional field → leave blank.
- Mandatory field → manual review.
- Never guess.
